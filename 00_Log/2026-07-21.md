# Caso test importante - diferentes comportamientos con [float16/float32/float64]

El caso que puede generar distintos comportamientos es aquel en que generemos esa cadena de bits. Para esto busque los valores:

```text
1 * 2^15  * 1.993  = 65280.0    = [0 - 1_1110 - 11_1111_1000]
1 * 2^6   * 1.9991 = 127.94     = [0 - 1_0101 - 11_1111_1111]
1 * 2^-4  * 1.9991 = 0.12494    = [0 - 0_1010 - 11_1111_1111]
1 * 2^-14 * 1.9991 = 0.00012202 = [0 - 0_0001 - 11_1111_1111]
```

esto en nuestro sumador genera las mantisas

```text
Mantisas signadas y alineadas:
  1: 0001 1111 1110 0000 0000 0000 0000 0000 0000
  2: 0000 0000 0000 1111 1111 1110 0000 0000 0000
  3: 0000 0000 0000 0000 0000 0011 1111 1111 1000
  4: 0000 0000 0000 0000 0000 0000 0000 0000 1111
```

generando un carry en la suma que cambia el resultado final de la mantisa que empaquetamos.

```text
65280.0 + 127.94 + 0.12494 + 0.00012202
redondeado como:
65280.0 + 127.9375 + 0.12493896484375 + 0.00012201070785522461 = 65408.0
```

Pero en un sumador secuencial usando exclusivamente `float16` llegamos a

```python3
>>> import numpy as np
>>> np.float16(65280) + np.float16(0.00012202) 
65280.0
>>> np.float16(65280.0)+np.float16(0.12494)
65280.0
>>> np.float16(65280.0)+np.float16(127.94)
65400.0

```
