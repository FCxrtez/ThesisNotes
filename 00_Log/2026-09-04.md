```python
def analyze_fp16():
    total = 2**16
    
    # Exponent 5 bits, Mantissa 10 bits, Sign 1 bit
    # exponent = bits 10-14
    
    nan_count = 0
    inf_count = 0
    subnormal_count = 0
    zero_count = 0
    normal_count = 0
    
    for i in range(total):
        sign = (i >> 15) & 1
        exp = (i >> 10) & 0x1F
        frac = i & 0x3FF
        
        if exp == 31:
            if frac == 0:
                inf_count += 1
            else:
                nan_count += 1
        elif exp == 0:
            if frac == 0:
                zero_count += 1
            else:
                subnormal_count += 1
        else:
            normal_count += 1
            
    print(f"Total: {total}")
    print(f"Inf: {inf_count} ({inf_count/total*100:.4f}%)")
    print(f"NaN: {nan_count} ({nan_count/total*100:.4f}%)")
    print(f"Subnormal (excl 0): {subnormal_count} ({subnormal_count/total*100:.4f}%)")
    print(f"Zero (+0/-0): {zero_count} ({zero_count/total*100:.4f}%)")
```

Reinterpreting a uniformly distributed random 16-bit integer (`uint16`) as an IEEE 754 half-precision floating-point number (`float16`) yields exact, deterministic probabilities because every bit pattern among the $2^{16} = 65,536$ total states is sampled with equal probability.

**Single Operand Probability Breakdown**

| Value Category | IEEE 754 Bit Field Criteria | Pattern Count ($N / 65536$) | Individual Operand Probability |
| --- | --- | --- | --- |
| **NaN** (Quiet & Signaling) | Exponent = `11111`, Mantissa $\neq 0$ | $2046$ | $3.12195\%$ |
| **Infinity** ($+\infty, -\infty$) | Exponent = `11111`, Mantissa $= 0$ | $2$ | $0.00305\%$ |
| **Total Exponent Specials** | Exponent = `11111` ($\text{NaN} + \pm\infty$) | $2048$ | $3.12500\%$ ($\frac{1}{32}$) |
| **Subnormals** | Exponent = `00000`, Mantissa $\neq 0$ | $2046$ | $3.12195\%$ |
| **Zeros** ($+0, -0$) | Exponent = `00000`, Mantissa $= 0$ | $2$ | $0.00305\%$ |
| **Normal Numbers** | Exponent $\in [1, 30]$ | $61440$ | $93.75000\%$ ($\frac{15}{16}$) |

**4-Operand Vector Probabilities**

When generating a vector of 4 independent `float16` operands, the occurrence of high-exponent special values ($\text{NaN}$ and $\pm\infty$) follows the binomial distribution $B(4, p)$ with $p = \frac{1}{32} = 0.03125$:

* **Expected Specials Per Vector**: $\mathbb{E}[X] = 4 \times 0.03125 = 0.125$ special values per vector (1 in every 8 test vectors on average).
* **At Least One Special Value ($\text{NaN}$ or $\pm\infty$)**:

$$P(X \ge 1) = 1 - \left(1 - \frac{1}{32}\right)^4 = 1 - \left(\frac{31}{32}\right)^4 = 1 - \frac{923,521}{1,048,576} \approx 11.9262\%$$


* **At Least One NaN**:

$$P(\text{NaN} \ge 1) = 1 - \left(1 - \frac{2046}{65536}\right)^4 \approx 11.9151\%$$


* **At Least One Non-Normal ($\text{NaN}, \pm\infty$, Subnormals, or Zeros)**:

$$P(\text{Non-Normal} \ge 1) = 1 - \left(1 - \frac{1}{16}\right)^4 = 1 - \left(\frac{15}{16}\right)^4 \approx 22.7524\%$$



**Exact Breakdown of Specials Count per Vector**

Using $\binom{4}{k} p^k (1-p)^{4-k}$ for $p = 0.03125$:

* **0 Specials**: $88.0738\%$
* **1 Special**: $11.3644\%$
* **2 Specials**: $0.5499\%$
* **3 Specials**: $0.0118\%$
* **4 Specials**: $0.0001\%$

If your verification target requires higher density for edge-case coverage (such as ALUs or tensor cores), pure uniform `uint16` randomization will leave roughly $88\%$ of your 4-operand vectors containing only normal numbers. Constrained exponent sampling or weighted bit-field generation is usually necessary to hit boundary conditions more efficiently.
